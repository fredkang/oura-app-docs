# Oura App Docs

Static privacy-policy and terms pages for my personal **Oura Ring OAuth2 integration** (part of my personal-assistant project), served via GitHub Pages at **https://eric-hastie.github.io/oura-app-docs/**.

This repo exists for one reason: Oura's developer-app registration requires public website, privacy-policy, and terms URLs, so these pages provide them. It's plumbing, not a showcase - please don't delete or rename it, or the registered OAuth app breaks.
